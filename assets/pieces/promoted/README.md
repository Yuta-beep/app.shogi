# Promoted Piece Images

Place promoted shogi piece images in this folder.

## Required filenames

- `tokin.png` (と金)
- `narikyo.png` (成香)
- `narikei.png` (成桂)
- `narigin.png` (成銀)
- `ryuo.png` (龍王 / promoted rook)
- `ryuma.png` (龍馬 / promoted bishop)

## Notes

- Use lowercase file names to avoid platform-specific path issues.
- Prefer transparent PNG.
- Recommended size: 256x256 or 512x512.
- Keep one piece per file.
